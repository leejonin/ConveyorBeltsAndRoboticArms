## 개요

Unity에서 컨베이어·다중 로봇팔·QR/카메라 분류·중앙뇌(Mock)·웹 제어판으로 공장 라인을 시뮬레이션한다.

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| 중앙뇌 | API로 호출하는 통합 LLM(현재 `MockCentralBrainClient`) |
| 제어판 | Play 중 `DashboardServer`가 제공하는 웹 UI |
| 에러 물류 | 스폰 단계 주입 이상 물류(`ErrorLogisticsKind`). **ErrorZone** 배정 |
| Pass / Fail / Error | `ItemSortOutcome` — NormalZone / UnprocessedZone / ErrorZone |

## 개념 설명

1. `ItemSpawner`가 벨트 위에 물품(및 확률적 에러 물류) 생성
2. `RobotStation`에서 QR·(선택) 도형 인식 후 `ConveyorPickDispatcher`가 팔에 집기·배치 배정
3. `FactoryStateRegistry`가 상태·통계·알림 집계
4. `BrainScheduler`가 주기적으로 스냅샷을 중앙뇌에 전달, `BrainCommandExecutor`가 허용 명령 실행
5. `DashboardServer`가 SSE로 제어판 갱신
