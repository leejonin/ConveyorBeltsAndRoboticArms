# ConveyorBeltsAndRoboticArms

Unity SmartFactory 시뮬레이션 — 컨베이어·로봇팔·3구역 물류·웹 대시보드.

- **원격 저장소**: https://github.com/leejonin/ConveyorBeltsAndRoboticArms
- **Unity**: 6000.0.35f1 (URP) — [Info/기술_환경.md](Info/기술_환경.md)
- **개발 문서**: [Info/README.md](Info/README.md)
- **Git·협업 규칙**: [Info/메인프로젝트/전체구조/001/Git_원격_저장소.md](Info/메인프로젝트/전체구조/001/Git_원격_저장소.md)

## 시작

1. 저장소 클론
2. Unity Hub에서 프로젝트 폴더 열기 (6000.0.35f1 권장)
3. 씬 `Assets/SmartFactory/Scenes/Factory.unity` 열기
4. Play — 대시보드 http://127.0.0.1:8080/ (기본 포트)

추가 에셋이 필요하면 [에셋_다운로드_지침.md](Info/메인프로젝트/전체구조/001/에셋_다운로드_지침.md)를 따릅니다.
